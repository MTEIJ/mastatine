# M.A. Mastatine (Mast Association) brand files

All stickers are 85 x 55 mm, square corners, text converted to outlines (no fonts needed).
`*-print.svg` has 2 mm bleed on every side (89 x 59 mm file, trim at 85 x 55 mm). `*-preview.*` is the finished
85 x 55 mm shape. Brand colours: orange `#f57f20`, ink `#161616`. Lettering is set in the Astatine display font.

- `logo/` the atom-and-tower mark: colour, mono (black) and white versions, SVG with strokes converted to outlines, plus PNG.
- `stickers/primary/` the main sticker (skyline with a red-tinted horizon, big centred lockup, black name band).
- `stickers/extras/` alternates: postcard/stamp, name tag, Mast of the Month, pixel world.
- `overview.png` all kept stickers side by side.
